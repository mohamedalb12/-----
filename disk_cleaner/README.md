# 🧹 Disk Cleaner Pro — منظّف القرص برو

برنامج مجاني ومفتوح المصدر لتنظيف جهاز الماك وتحرير المساحة. واجهته عصرية تدعم الوضع الداكن والفاتح.

## ✨ المميزات

| الصفحة | ماذا تفعل |
|---|---|
| 🏠 **الرئيسية** | تعرض مساحة القرص في رسم دائري متحرك. زر **«فحص ذكي»** يفحص كل شيء دفعة واحدة، وزر **«تنظيف الآن»** يحذف المهملات الآمنة. وتعرض أيضاً المساحة التي وفّرتها حتى الآن. |
| 🧹 **مهملات النظام** | تجمع الكاش لكل تطبيق، وسجلات النظام، والملفات المؤقتة القديمة، وسلة المحذوفات، ومخلفات Xcode وnpm وGradle، وملفات ‎.dmg المنسية، ونسخ iPhone الاحتياطية. ويمكنك أيضاً فحص أي مجلد تختاره. |
| 📦 **الملفات الكبيرة والقديمة** | تحدد فيها الحجم الأدنى بشريط تمرير، وعمر الملف (أقدم من شهر أو سنة أو غيرهما). النتائج مُجمّعة حسب النوع (فيديو، صور، أرشيفات...) ويمكن تصديرها إلى ملف CSV. |
| 👯 **الملفات المكررة** | تقارن محتوى الملفات بايت ببايت (بصمة BLAKE2)، وتحدد تلقائياً كل النسخ عدا النسخة الأصلية. |
| 🧩 **إلغاء التثبيت** | تحذف التطبيق مع كل ملفاته في Library: الإعدادات، والكاش، والحاويات، وعناصر بدء التشغيل. فيها أيضاً **إعادة ضبط** التطبيق، والبحث عن **بقايا تطبيقات حذفتها سابقاً**. |
| 🗺 **خريطة المساحة** | تعرض المجلدات مرتبة من الأكبر للأصغر بأعمدة ملونة، وتنتقل بينها بنقرة. وفيها رسم يوضح توزيع المساحة حسب نوع الملف. |
| ⚙️ **الإعدادات** | تختار فيها المظهر وطريقة الحذف الافتراضية، وتضيف مجلدات يتجنّبها الفحص، وترى إحصاءاتك. |

**مع كل ملف:** نقر مزدوج لفتحه، و**مسافة** للمعاينة السريعة (Quick Look)، وزر يمين لإظهاره في Finder أو نسخ مساره.

### 🛡 الأمان أولاً
- **الحذف الافتراضي ينقل الملفات إلى سلة المحذوفات**، فيمكنك استرجاعها. والحذف النهائي يتطلّب تأكيداً إضافياً.
- لا يحذف البرنامج شيئاً داخل مجلدات النظام المحمية مثل ‎/System و ‎/usr، ولا يحذف مجلداتك الأساسية نفسها (مثل Documents وDesktop).
- يعامل الحِزم مثل مكتبة الصور و‎.app كملف واحد، فلا يحذف جزءاً من داخلها فيُفسدها.
- عند حذف ملفات مكررة، يحذّرك إذا كنت على وشك حذف كل النسخ.
- أخطاء الصلاحيات لا توقف الفحص. يتخطّى البرنامج تلك المجلدات ويعرض عددها.
- كل عمليات الفحص والحذف تعمل في الخلفية، فلا تتجمّد الواجهة، ويمكنك إيقاف أي فحص في أي وقت.

## 📥 التثبيت (تطبيق جاهز)

1. ادخل صفحة **Releases** في هذا المستودع وحمّل ملف الـ DMG المناسب لجهازك:
   - **Apple M1/M2/M3/M4** ← الملف المنتهي بـ `arm64.dmg`
   - **Intel** ← الملف المنتهي بـ `x86_64.dmg`

   تعرف نوع جهازك من قائمة  ← **حول هذا الماك**، في خانة «الشريحة» أو «المعالج».
2. افتح ملف DMG، ثم اسحب **Disk Cleaner Pro** إلى مجلد **Applications**.
3. **أول تشغيل:** التطبيق غير موقّع بشهادة مطوّر من Apple (الشهادة تكلّف 99$ سنوياً)، لذلك سيظهر تحذير. الحل:
   - افتح التطبيق مرة واحدة واضغط «تم».
   - افتح **إعدادات النظام ← الخصوصية والأمان**، وانزل للأسفل، ثم اضغط **«فتح على أي حال»**.
   - أو نفّذ هذا الأمر في Terminal:
     ```bash
     xattr -dr com.apple.quarantine "/Applications/Disk Cleaner Pro.app"
     ```
4. **لفحص أعمق (موصى به):** افتح **إعدادات النظام ← الخصوصية والأمان ← الوصول الكامل للقرص**، وأضف **Disk Cleaner Pro**.

## 🛠 التشغيل من الكود

```bash
cd disk_cleaner
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```
يحتاج Python 3.9 أو أحدث مع Tkinter. إذا ظهر خطأ `No module named tkinter`، ثبّت Python من [python.org](https://www.python.org/downloads/macos/) أو نفّذ `brew install python-tk`.

## 📦 بناء التطبيق (.app و .dmg) بنفسك

على جهاز ماك:
```bash
cd disk_cleaner
./build_mac.sh
```
النتيجة في `dist/`: الملف `Disk Cleaner Pro.app`، والملف `DiskCleanerPro-<version>-<arch>.dmg`.

**البناء التلقائي:** عند كل تحديث للكود، يبني GitHub Actions التطبيق على أجهزة ماك حقيقية (Apple Silicon وIntel)، ويشغّل عليه اختباراً ذاتياً، ثم ينشر ملفات DMG في صفحة Releases. الإعدادات في `.github/workflows/build-macos.yml`.

**الاختبار الذاتي:**
```bash
python3 main.py --selftest
```
يشغّل كل دوال الفحص على النظام الحقيقي، ويفتح كل صفحات الواجهة ويتأكد أنها تعمل.
