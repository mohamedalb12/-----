# 🧹 منظّف القرص — Disk Cleaner

برنامج مكتبي بلغة Python بواجهة رسومية حديثة (CustomTkinter). يفحص القرص ويعرض الملفات الكبيرة والملفات المؤقتة والمهملة، ويتيح لك فتحها أو إظهارها في Finder أو حذفها بأمان.

## المميزات
- **واجهة حديثة** تدعم الوضع الداكن والفاتح، مع شريط تقدّم ونسبة مئوية.
- **جدول نتائج** يعرض: اسم الملف، الحجم (KB/MB/GB)، النوع، التصنيف، والمسار الكامل. يمكنك الترتيب بالضغط على عنوان العمود، والتصفية حسب التصنيف، والبحث بالاسم.
- **فحص الملفات الكبيرة** مع شريط تمرير لاختيار الحد الأدنى للحجم (من 10MB إلى 10GB).
- **فحص الملفات المهملة**:
  - الكاش (`~/Library/Caches`، `.cache`، `__pycache__`، كاش المتصفحات ...)
  - الملفات المؤقتة (`.tmp`، `.bak`، `.swp`، `.crdownload`، `/private/var/folders` ...)
  - السجلات (`.log`، `~/Library/Logs`، تقارير الأعطال)
  - سلة المحذوفات (`~/.Trash`)
  - بقايا البرامج (Xcode DerivedData، ملفات `.dmg`/`.pkg` المنسية في التنزيلات ...)
  - ملفات نظام مهملة (`.DS_Store`، `._*`)
- **الفحص يعمل في الخلفية** (Thread منفصل)، فلا تتجمّد الواجهة، ويمكنك إيقافه في أي وقت.
- **التعامل مع الملفات**:
  - نقر مزدوج أو زر «فتح الملف» ← يفتح الملف بالبرنامج الافتراضي.
  - زر «إظهار في Finder» ← يفتح المجلد ويحدّد الملف.
  - زر «حذف المحدد» ← نافذة تأكيد، والخيار الافتراضي هو **النقل إلى سلة المحذوفات** (يمكن استرجاعه). الحذف النهائي يتطلّب تأكيداً إضافياً.
  - قائمة بالزر الأيمن تحتوي أيضاً على «نسخ المسار». يمكنك تحديد أكثر من ملف بالضغط على ⌘ أو Shift.
- **أخطاء الصلاحيات لا توقف البرنامج**: المجلدات غير المسموح بقراءتها يتم تخطّيها، ويظهر عددها في شريط الحالة.
- **حماية**: البرنامج لا يحذف شيئاً داخل مجلدات النظام المحمية مثل `/System` و `/usr/bin`، ويتخطّى عند فحص القرص كاملاً المجلدات التي تكرّر نفس الملفات (`/System/Volumes` و `/Volumes`).

## التثبيت والتشغيل على macOS

### 1) تأكّد من وجود Python 3.9 أو أحدث مع Tkinter
افتح تطبيق **Terminal** ونفّذ:
```bash
python3 --version
python3 -m tkinter
```
إذا ظهرت نافذة صغيرة فـ Tkinter يعمل. إذا ظهر خطأ أو لم يكن Python مثبتاً:
- **الطريقة الأسهل:** حمّل Python من [python.org](https://www.python.org/downloads/macos/)، فهو يأتي مع Tkinter جاهزاً.
- **أو باستخدام Homebrew:**
  ```bash
  brew install python python-tk
  ```

### 2) ثبّت المكتبات المطلوبة (يُفضّل داخل بيئة افتراضية)
```bash
cd path/to/disk_cleaner
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3) شغّل البرنامج
```bash
python3 main.py
```
(في المرات التالية: `cd` إلى المجلد، ثم `source .venv/bin/activate`، ثم `python3 main.py`)

### 4) صلاحية الوصول الكامل للقرص (اختيارية لكن مهمة)
يحمي macOS بعض المجلدات، مثل `~/Library/Mail` وجزء من `~/Library` و Safari. لكي يفحصها البرنامج:
**System Settings ← Privacy & Security ← Full Disk Access** ثم فعّل **Terminal** (أو التطبيق الذي تشغّل منه البرنامج)، وأعد تشغيله.
بدون هذه الصلاحية سيعمل البرنامج بشكل طبيعي، لكنه سيتخطّى هذه المجلدات ويذكر عددها في شريط الحالة.

> عند النقل إلى سلة المحذوفات قد يطلب macOS مرّة واحدة السماح لـ Terminal بالتحكّم في Finder. هذا طبيعي، فالبرنامج يستخدم Finder كطريقة بديلة إذا فشلت مكتبة Send2Trash.

## بنية الملفات
| الملف | الوظيفة |
|---|---|
| `main.py` | الواجهة الرسومية: الأزرار، الجدول، شريط التقدّم، نافذة تأكيد الحذف |
| `scanner.py` | منطق الفحص في خيط خلفي، وقواعد التعرّف على الملفات المهملة |
| `file_actions.py` | فتح الملف، إظهاره في Finder، النقل إلى السلة، الحذف النهائي |
| `requirements.txt` | المكتبات المطلوبة |

## كيف يعمل الفحص؟
1. **حصر الملفات:** مرور سريع على المجلدات لمعرفة عدد الملفات الكلّي، حتى نحسب النسبة المئوية. يتحرّك شريط التقدّم في هذه المرحلة دون نسبة محدّدة.
2. **الفحص:** قراءة حجم كل ملف وتصنيفه، وإرسال النتائج إلى الواجهة على دفعات عبر `queue.Queue`. الواجهة تقرأ هذه النتائج كل 100ms، لأن Tkinter لا يسمح بتعديل الواجهة من خيط آخر.

لا يتتبّع البرنامج الروابط الرمزية (Symlinks)، فلا يدخل في حلقات لا نهائية ولا يحسب نفس الملف مرتين. ويعرض الجدول أكبر 10,000 نتيجة كحدّ أقصى للحفاظ على سرعة الواجهة.

## نصائح للاستخدام الآمن
- لا تحذف ملفات الكاش أو المؤقتات التابعة لتطبيقات مفتوحة حالياً. أغلق التطبيق أولاً.
- استخدم دائماً «النقل إلى سلة المحذوفات»، وأفرغ السلة بنفسك بعد التأكّد أن كل شيء يعمل.
- ملفات داخل `/Library` أو `/private` قد تحتاج صلاحيات المدير (sudo) لحذفها، والبرنامج سيخبرك إذا فشل الحذف.
